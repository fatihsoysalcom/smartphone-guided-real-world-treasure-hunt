# Smartphone Guided Real World Treasure Hunt

This example demonstrates how a simple web page can facilitate a real-world treasure hunt, using technology to provide clues and validate progress. It simulates a smartphone app guiding users to physical locations where they must find specific information (answers) to advance. The goal is to encourage physical interaction and observation, using the device as a tool rather than a distraction.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
